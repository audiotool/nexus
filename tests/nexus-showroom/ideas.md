# Showroom ideas

A running list of feedback to consider for the Nexus showroom. Don't act on
these unless explicitly asked — just capture.

- The entity categories in the Project Overview don't add up to "Total
  Entities", which is confusing. Either reconcile the categories so they
  partition the total, or rename / explain the discrepancy.
- Potentially remove the "nexus" term from user-facing copy. It's an
  internal name that doesn't help users understand what they're looking at.
- Explain what each box (example card) does. Right now the title alone
  doesn't make the purpose obvious; a one-liner under each title would help.
- Put all device icons into a public repo so the showroom (and any other
  third-party tooling) can render them next to device names.
